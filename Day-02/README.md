# Day 02 – Retail Sales Intelligence System

## Project Overview
A Python-based retail sales analysis project that analyzes customer spending, product performance, and category-wise revenue using a sample sales dataset.

## Objectives
- Calculate total store revenue.
- Analyze product-wise quantity and revenue.
- Identify the highest-spending customer.
- Compare revenue across product categories.
- Generate ranked product and customer reports.
- Calculate category-wise revenue contribution.

## Technologies Used
- Python 3
- Core Python
- Dictionaries and Lists
- Loops and Conditional Statements
- Sorting and Lambda Functions

## Key Business Insights
1. **Electronics dominates revenue:** Contributes 95.24% of total store revenue.
2. **Laptop is the top product:** Generates ₹1,00,000 in revenue.
3. **High-value customers:** Customers A and B are the top spenders, contributing ₹71,500 and ₹51,000 respectively.

## Key Results
- Total Store Revenue: ₹147,000
- Highest Spending Customer: A
- Highest Revenue Category: Electronics
- Top Product: Laptop

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run:

```bash
python retail_sales_intelligence.py
```

## Concepts Practiced
Data aggregation, dictionary manipulation, nested dictionaries, loops, sorting, ranking, percentage calculations, and analytical problem-solving.

Beginner-to-Intermediate Python Coding Practice.
