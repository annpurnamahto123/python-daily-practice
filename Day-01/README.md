# Day 01 – Employee Salary Intelligence

## Problem Overview
Analyze employee salary records across different departments to generate useful salary insights.

## Questions Solved

1. Calculate the average salary for each department.
2. Find the highest-paid employee in each department.
3. Identify employees earning above their department's average salary.
4. Rank employees within each department by salary.
5. Find the department with the highest average salary.

## Concepts Practiced
- Python Dictionaries
- Nested Dictionaries
- Lists
- For Loops
- Conditional Statements
- Dictionary Methods (`items()`)
- Sorting (`sorted()`)
- Lambda Functions
- `enumerate()`

## Key Learning
- Grouping employee records by department.
- Calculating department-wise salary averages.
- Comparing employee salaries.
- Sorting and ranking employees.
- Finding maximum values using loops and conditions.
